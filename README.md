# Person-CRUD-App

A small React application for managing a list of people.

Technologies:
React
JavaScript
Vite
CSS
localStorage
Getting Started
Installation

Clone the repository and install the dependencies:

npm install
Run the application

Start the development server:

npm run dev

The application will then be available in the browser at the local development address shown in the terminal.

Project Structure
src/
├── components/
├── App.jsx
├── main.jsx
└── ...
Data Storage

The application currently uses the browser's localStorage to persist the list of people between page reloads.

Notes

This project was created as a practical exercise to demonstrate working with React, forms, validation, component structure, and client-side data storage.
